## Dataset Sources & Setup
- **OULAD (Open University Learning Analytics Dataset)**:
  - Download from: https://archive.ics.uci.edu/dataset/349/open+university+learning+analytics+dataset
  - Place the downloaded archive as `data/oulad/archive.zip` (contains `studentVle.csv`, `studentInfo.csv`, `courses.csv`).
- **Moodle Log Data**:
  - Place the course activity log as `data/moodle/logs.csv`.

Python packages: pandas, numpy, scikit-learn, scipy, matplotlib. Figure 6 (transition networks) is drawn in the Carm TNA notebook, not in Python; the Python notebook computes the transition probabilities and the permutation test.


## Main analysis choices
- OULAD: Pass/Distinction vs Fail; Withdrawn excluded from the whole-course models. 5-fold GroupKFold by `id_student`, scaling fitted inside each fold.
- Moodle: end-exam quiz events (`IT_EE_*`) and quiz auto-saves removed; study period 23 Oct 2025 – 8 Feb 2026; 30-minute sessions; learners with ≥3 sessions and ≥3 active days. Features log-transformed before K-Means (k = 4, chosen on silhouette, bootstrap stability and agreement with Ward clustering).
- Synopsis submission and exam attempt are used only for validation and as prediction targets, never as clustering features.
- TNA: per-profile transition probabilities within sessions; permutation test shuffling learners (2,000 shuffles) with Benjamini–Hochberg correction.
